Demande d'inscription

Pour les parents qui souhaitent utiliser le planning et, si disponible, le suivi du transport scolaire.

1. Compte Parent

Crée ton compte avec ton adresse e-mail, puis confirme-la depuis le message Firebase. Tu peux aussi utiliser un compte TACLAR existant.

2. Demande pour mon enfant

Demande pilote : connecte-toi, confirme ton e-mail, puis transmets ton dossier à l’administration. Aucun abonnement n’est activé automatiquement.

Indicatif +241 prérempli. Les espaces sont ajoutés automatiquement.

Cette école doit être ajoutée par l'administration avant de pouvoir choisir une classe. Aucun établissement inconnu ne sera créé automatiquement.

Classe présente dans le planning historique : importation Firebase nécessaire avant activation.

Protection des données : seul le parent connecté peut déposer sa demande. Si les règles Firebase ne sont pas encore publiées, l’envoi sera refusé sans enregistrer le dossier.

Ne saisis pas d'adresse exacte du domicile, de mot de passe ou de document médical dans ce formulaire de démonstration.
